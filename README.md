# make-knowledge-cards

`make-knowledge-cards` 是一个 Agent Skill，帮助把文章整理成可用于学习和复习的知识卡片。

## 解决的问题

长文章通常包含重复内容、次要细节和分散的重点，直接复习不容易抓住核心。本 Skill 按重要性提炼知识，合并重复观点，并要求每张卡片只讲一个知识点；所有内容都以原文为依据，避免编造和为了凑数而拆分。

## 主要功能

- 将对话中粘贴的文章，或用户指定的本地 Markdown（`.md`）/纯文本（`.txt`）文件整理成卡片。
- 来源支持时生成 5–8 张卡片；信息不足时少于 5 张，并说明原因。
- 每张卡片包含标题、核心知识、简明解释、例子和自测问题。
- 优先使用原文例子；原文没有可用例子时明确标注“原文未提供具体例子”。
- 使用原文语言，不添加原文未支持的事实；不修改输入文件。

**暂不支持：** 网页抓取、PDF、Anki 卡组和图形界面。

## 安装方法

这是供支持 Agent Skills 的 AI 助手读取的指令文件，不是独立应用，没有需要安装的运行依赖。安装时复制整个 Skill 文件夹，不要只复制 `SKILL.md`。

**Codex：** 将文件夹复制到个人 Skill 目录 `$HOME/.agents/skills/`，或项目 Skill 目录 `.agents/skills/`。例如，在仓库根目录使用 PowerShell 安装到个人目录：

```powershell
New-Item -ItemType Directory -Force "$HOME\.agents\skills" | Out-Null
Copy-Item -Recurse ".\test\skills\make-knowledge-cards" "$HOME\.agents\skills\make-knowledge-cards"
```

复制后按 Codex 的说明重新加载或重启，使新 Skill 生效。其他支持 Agent Skills 的助手，请将文件夹放到其文档规定的 Skill 目录，并按其说明加载。

本项目中的 Skill 源文件位于 [`test/skills/make-knowledge-cards`](test/skills/make-knowledge-cards)。

## 使用方法

在已加载该 Skill 的 AI 助手中：

- **粘贴文章：** 请求“使用 make-knowledge-cards 把下面文章整理成知识卡片”，然后附上文章。
- **使用本地文件：** 请求“使用 make-knowledge-cards 整理文件 `路径\文章.md`”，并提供可访问的 `.md` 或 `.txt` 文件路径。

Skill 会阅读所提供的完整来源，再按来源内容生成卡片；不会抓取网页或处理 PDF。

## 输入与输出示例

**输入**

> 主动回忆是指不看学习材料，尝试从记忆中提取所学内容。它能帮助学习者发现尚未掌握的信息。间隔练习是把学习分散到不同时间进行，而不是集中在一次完成。学习者可以先尝试回忆，再隔一段时间复习；如果答错，可以回看材料并再次练习。

**输出**

主题：学习方法（3 张卡片；示例原文只支持这 3 个独立知识点）

### 卡片 1：主动回忆

- **核心知识：** 主动回忆是在不看学习材料时，尝试从记忆中提取所学内容。
- **简明解释：** 这种做法可以帮助学习者发现尚未掌握的信息。
- **例子：** 不看材料，先尝试回忆刚学过的内容。
- **自测问题：** 主动回忆时，学习者要尝试做什么？

### 卡片 2：间隔练习

- **核心知识：** 间隔练习是把学习分散到不同时间，而不是集中在一次完成。
- **简明解释：** 原文将学习时间分散与一次性集中学习作对比。
- **例子：** 把复习安排在不同时间进行。
- **自测问题：** 间隔练习与集中在一次完成有什么区别？

### 卡片 3：答错后的复习流程

- **核心知识：** 回忆答错时，可以回看材料并再次练习。
- **简明解释：** 这是原文给出的处理答错的步骤。
- **例子：** 先尝试回忆；若答错，则回看材料后再次练习。
- **自测问题：** 按原文所述，回忆答错后可以怎么做？
